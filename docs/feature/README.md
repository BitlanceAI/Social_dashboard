## Product scope

The application is a workspace-based social publishing platform. It supports Facebook Pages, connected Instagram Business accounts, and LinkedIn profiles. LinkedIn organization support exists in the server but remains dormant until the required LinkedIn permissions are enabled. Paid advertising is not part of the product.
